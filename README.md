# Телеграм-бот сигналів MEXC Futures — свічки 5 хвилин

Бот отримує готові свічки з інтервалом 5 хвилин безпосередньо з API MEXC Futures. Він не об’єднує хвилинні свічки самостійно.

## Налаштування Railway

Додайте змінні `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID` у розділі Variables. За потреби можна задати `MEXC_SYMBOLS=BTCUSDT,ETHUSDT` і `POLL_SECONDS=15`.

## Як працює бот

- Використовує готові закриті свічки 5 хвилин із MEXC Futures.
- Під час першого запуску завантажує історію без надсилання старих сигналів.
- Надсилає попередження в останню хвилину поточної свічки №8, якщо умови ще виконуються.
- Надсилає сигнал після закриття свічки №8, якщо свічки №7 і №8 підтвердили умову свічки №6.
- Перевіряє результат на свічках №9–№15: перша свічка очікуваного кольору означає успіх; якщо до №15 її немає — неуспіх.
- Бот лише надсилає повідомлення і не відкриває угод.

## Важливо

Після розгортання перевірте журнали Railway та наявність повідомлення «Бот запущено» в Telegram-групі. Для збереження стану між перезапусками потрібне постійне сховище Railway. Не публікуйте файл `.env` і не додавайте його до відкритого репозиторію.

## Виправлення помилки встановлення Python у Railway

У корені проєкту є `mise.toml` з налаштуванням `python.github_attestations = false`, яке відповідає рекомендованому повідомленням mise способу усунення помилки `No GitHub artifact attestations found`. Це змінює лише перевірку атестацій завантажуваного Python; використовуйте ZIP лише у власному проєкті.
